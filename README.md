# Kristalliner Project

## Project Description
ระบบจัดการการเรียนรู้ออนไลน์สำหรับนักศึกษาสาขาเทคโนโลยีเว็บ

## Objectives
- เพื่อสร้างพื้นที่จัดเก็บสื่อการเรียนรู้แบบศูนย์รวม
- เพื่อให้นักศึกษาสามารถติดตามความก้าวหน้าการเรียนได้ด้วยตนเอง
- เพื่อประยุกต์ใช้แพลตฟอร์ม GitHub ในการพัฒนาเว็บ

## Target Users
นักศึกษาและอาจารย์ผู้สอนในรายวิชาการประยุกต์ใช้เทคโนโลยีเว็บและแพลตฟอร์ม

## Main Features
- ระบบแสดงรายการบทเรียนและใบงาน
- ระบบส่งงานและอัปโหลดไฟล์หลักฐาน
- แดชบอร์ดติดตามความก้าวหน้า

## Technology
- HTML5 / CSS3 / JavaScript
- Node.js & Express
- GitHub API
